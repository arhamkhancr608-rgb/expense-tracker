# 💰 Expense Tracker

A simple and responsive web-based Expense Tracker built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

[Open Expense Tracker](https://arhamkhancr608-rgb.github.io/expense-tracker/)

## ✨ Features

- ➕ Add expenses
- 🗑️ Delete expenses
- 🗂️ Categorize expenses
- 💰 Calculate total spending
- 📊 Track number of transactions
- 📈 Spending by category chart
- 💾 Save expenses using LocalStorage
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage
- GitHub Pages
